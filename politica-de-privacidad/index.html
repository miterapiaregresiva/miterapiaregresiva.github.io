Política de privacidad

Este sitio es una web estática y no utiliza herramientas propias de analítica, publicidad o seguimiento.

Cookies y seguimiento

El código de esta web no instala cookies ni utiliza almacenamiento local del navegador para analítica, publicidad o seguimiento. No incorpora píxeles de Meta ni un chat de WhatsApp integrado. Los servicios externos que abras desde los enlaces del sitio aplican sus propias políticas de privacidad y cookies.

Alojamiento y distribución: GitHub Pages y Fastly

Esta web está alojada en GitHub Pages, un servicio de GitHub, Inc. Al visitar un sitio alojado en GitHub Pages, GitHub registra y almacena la dirección IP del visitante por motivos de seguridad, incluso si no tiene una cuenta de GitHub. Más información en la política de privacidad de GitHub.

La entrega de las páginas utiliza la red de distribución de contenidos (CDN) de Fastly, Inc., como parte de la infraestructura de GitHub Pages. Este servicio permite almacenar temporalmente y distribuir los archivos para agilizar su carga. Fastly trata las solicitudes de red necesarias para entregar el contenido y recoge direcciones IP de forma limitada para prestar y mejorar sus servicios. Más información en la política de privacidad de Fastly.

DNS y redirección de www: Cloudflare

El dominio miterapiaregresiva.com utiliza los servidores DNS de Cloudflare, Inc. para resolver el nombre del dominio y localizar el servidor de la web. Además, las solicitudes a www.miterapiaregresiva.com pasan por Cloudflare, que las redirige a miterapiaregresiva.com. Para atender esa conexión, Cloudflare puede tratar la dirección IP y datos técnicos de la solicitud, como la URL solicitada y la información de conexión. La respuesta de redirección también incluye cabeceras de notificación de errores de red (NEL), que permiten a navegadores compatibles enviar informes técnicos de fallos a Cloudflare. En la configuración comprobada el 7 de octubre de 2026, el dominio sin www resuelve directamente a GitHub Pages. Por ello, no se describe Cloudflare como un servicio que filtre todas las comunicaciones de navegación del sitio. Más información en la política de privacidad de Cloudflare.

Contacto por WhatsApp e Instagram

El botón flotante de WhatsApp y el enlace de la página de contacto son enlaces a wa.me. No son un widget de chat integrado: esta web no carga scripts, iframes ni cookies de Meta o WhatsApp para mostrarlos. Al pulsarlos accedes a WhatsApp, que aplica sus propias condiciones y política de privacidad. El enlace incluye un texto de saludo predefinido; abrirlo no envía automáticamente un mensaje.

Si decides enviarnos un mensaje por WhatsApp, recibiremos tu número de teléfono y la información que compartas para atender tu consulta. Evita enviar información sensible sobre tu salud en el primer contacto. En el Espacio Económico Europeo, el proveedor de WhatsApp es WhatsApp Ireland Limited, según sus condiciones aplicables.

El sitio también enlaza al perfil de Instagram @miterapiaregresiva. No incorpora publicaciones ni scripts de Instagram; al abrir el enlace utilizas un servicio externo sujeto a su propia política de privacidad.

Imágenes y enlaces externos

La biblioteca, el índice de autores y la ficha de Brian Weiss incluyen una imagen alojada en Wikimedia Commons. Cuando el navegador carga esa imagen, realiza una petición a Wikimedia que comunica datos técnicos, como la dirección IP, necesarios para servirla. No es necesario pulsar un enlace para que se produzca esa petición. Consulta la política de privacidad de Wikimedia.

La Biblioteca de terapia regresiva contiene enlaces a recursos externos, como Internet Archive, Open Library y la Red de Bibliotecas de Canarias. Estos enlaces no incrustan los recursos en esta web. Al abrirlos, los servicios de destino aplican sus propias condiciones y políticas de privacidad.
